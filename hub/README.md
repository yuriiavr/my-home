# 🧠 Розумний Дім — Хаб (додаток)

Центральний "мозок": один інтерфейс для всіх пристроїв, **незалежно від бренду**.

## Як запустити (Windows)
```bash
# 1. Встанови залежності (один раз):
pip install -r requirements.txt

# 2. Запусти сервер (з папки hub):
uvicorn main:app --reload

# 3. Відкрий у браузері:
#    http://localhost:8000          — інтерфейс
#    http://localhost:8000/docs     — авто-сторінка тестування API
```

## Що зараз
Усі пристрої — "фейкові" (`MockDevice`), щоб бачити роботу **без заліза**.
Тиснеш плитку → стан міняється. Це повноцінний каркас, у який далі
підключатимемо справжні пристрої.

## Як додати реальний пристрій (будь-який бренд)
1. Створи драйвер у `devices/` — клас, що успадковує `Device` і реалізує `apply()`.
2. Заміни `MockDevice(...)` на свій клас у `main.py`.

Решта системи (API, інтерфейс) **не змінюється** — у цьому вся ідея.

## Структура
```
hub/
├── main.py            # сервер, реєстр пристроїв, API
├── requirements.txt   # залежності
├── devices/
│   ├── base.py        # інтерфейс Device — серце розширюваності
│   └── mock.py        # тестовий драйвер (без заліза)
└── static/            # веб-інтерфейс (майбутня PWA)
    ├── index.html
    ├── app.js
    └── style.css
```
