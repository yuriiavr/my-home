# Деплой хмарної версії (керування з будь-якого місця)

Вебзастосунок один — він живе у папці **`webapp/`** у корені проєкту.
Ця папка містить лише те, що потрібно ДОДАТКОВО для хмарного деплою:

| Файл                | У git? | Призначення                                        |
|---------------------|--------|----------------------------------------------------|
| `config.js`         | ❌ НІ  | Реальні дані MQTT-брокера (HiveMQ Cloud)           |
| `config.example.js` | ✅ так | Шаблон: скопіюй як `config.js` і заповни своїми даними |

## Як задеплоїти (Cloudflare Pages, безкоштовно)

1. Зайди на https://dash.cloudflare.com → **Workers & Pages** → **Create** →
   вкладка **Pages** → **Upload assets**.
2. Назви проєкт (наприклад `rozumnyi-dim`) → **Create project**.
3. Перетягни у вікно завантаження **УСІ файли з папки `webapp/`**
   (index.html, app.js, style.css, manifest.webmanifest, іконки)
   **ПЛЮС файл `deploy-cloud/config.js`** — саме файли, не папки,
   щоб index.html і config.js опинилися поруч у корені сайту.
4. Натисни **Deploy site** → отримаєш адресу типу `https://rozumnyi-dim.pages.dev`.
5. Відкрий її на телефоні → «Додати на початковий екран» — і керуй кондиціонером
   з будь-якого місця.

Оновлення: той самий проєкт → **Create new deployment** → перетягни файли знову
(так само: `webapp/*` + `config.js`).

## Як це працює

- Якщо поруч з index.html лежить `config.js` (задано `window.HUB_CONFIG`) і
  завантажилась бібліотека mqtt — застосунок працює через **MQTT-брокер** (хмара).
- Якщо `config.js` немає — застосунок працює через **локальний /api**
  (Python-хаб або сама плата). Тому в `webapp/` файла config.js НЕМАЄ і не має бути.

## ⚠️ Безпека

- `config.js` потрапляє на публічний хостинг у відкритому вигляді — його бачить
  кожен, хто відкриє сайт. Тому:
  - створи в HiveMQ Cloud **окремий обмежений логін** лише для веб-клієнта
    (доступ тільки до топіків `smarthome/…/#`) і вкажи його в `config.js`;
  - **не публікуй адресу сайту** (пряме посилання = пульт від твого кондиціонера);
  - за потреби зміни пароль у HiveMQ і передеплой з новим `config.js`.
- `config.js` навмисно в `.gitignore` — ніколи не коміть його в репозиторій.
