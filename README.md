# 🏠 Розумний будинок на ESP32 (ІЧ-керування)

«Розумний пульт»: ESP32 записує ІЧ-сигнали з пультів і відтворює їх — вручну,
за розкладом або віддалено.

## Архітектура (куди прямуємо)

```
              ІНТЕРНЕТ
  [Телефон] ─────┐
                 ▼
        ┌─────────────────────┐         домашня WiFi
        │  СЕРВЕР (приставка)  │   ┌──────────────────┐
        │  • Mosquitto (MQTT)  │◄──┤  ESP32 + ІЧ-діод │──> 📺 пульти
        │  • Home Assistant    │   │  (запис/відправка)│
        │  • розклади 9:00 ... │   └──────────────────┘
        └─────────────────────┘
```

## Етапи

- [x] **Етап 1 — прошивка ESP32:** запис / збереження / відтворення ІЧ + локальний веб-інтерфейс (`firmware/`)
- [ ] **Етап 2 — MQTT:** керування через брокер (з вулиці, з телефону)
- [ ] **Етап 3 — сервер:** перепрошивка приставки, Mosquitto + Home Assistant, розклади

---

## 🔌 Схема підключення (Етап 1)

| Компонент | Нога компонента | ESP32 |
|---|---|---|
| ІЧ-приймач VS1838B/TSOP38238 | OUT | GPIO15 |
| | VCC | 3V3 |
| | GND | GND |
| ІЧ-світлодіод (через транзистор 2N2222) | анод (+) через резистор | до 3V3 |
| | керування базою через резистор ~1кОм | GPIO4 |
| | емітер | GND |

> ІЧ-діод **не** під'єднуй напряму до GPIO — не вистачить струму на дальність.
> Транзистор (2N2222/BC547) як ключ + резистор 100–220 Ом у колі діода.

ІЧ-приймач (3 ноги) — для **запису**. ІЧ-діод — для **відправки**.

## 🚀 Як залити прошивку

### Варіант A — PlatformIO (рекомендую, ти вже у VS Code)
1. Встанови розширення **PlatformIO IDE** у VS Code.
2. Відкрий папку `firmware/` як проєкт.
3. У `src/main.cpp` впиши свої `WIFI_SSID` і `WIFI_PASS`.
4. Натисни **Upload** (стрілка вправо внизу). Бібліотеки підтягнуться самі.
5. Відкрий **Serial Monitor** — там буде IP-адреса, напр. `http://192.168.1.50`.

### Варіант B — Arduino IDE
1. Постав підтримку плат ESP32 (Boards Manager → "esp32").
2. Бібліотеки: **IRremoteESP8266**, **ArduinoJson** (Library Manager).
3. Скопіюй `firmware/src/main.cpp` у скетч `main.ino`, впиши WiFi, залий.

---

## 🧪 Як користуватись (Етап 1)
1. Відкрий IP ESP32 у браузері (телефон/ПК у тій самій WiFi).
2. Впиши назву (напр. `tv_on`), натисни **Записати**, наведи пульт і натисни кнопку.
3. Команда з'явиться у списку — тисни **▶ Надіслати**, щоб відтворити.

Команди зберігаються у пам'яті ESP32 (LittleFS) і не зникають після перезавантаження.

## 📍 Далі
Коли Етап 1 запрацює — додаємо MQTT (Етап 2), щоб ці ж команди можна було
надсилати з сервера за розкладом і з телефону з будь-якого місця.
